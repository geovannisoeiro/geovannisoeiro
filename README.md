# Geovanni Soeiro

**AI Systems Engineer.** I build systems *around* models — not prompts.

Most AI work stops at "which model should I use?". The harder question is what to build around it: memory, identity, tools, state, evaluation, and behavior that stays consistent over time.

I'm building **[THINK I.N.G](https://github.com/geovannisoeiro/think-ning-lab)** — a cognitive systems lab — and documenting the whole process.

---

### The lab

Three agents, built as entities with a voice rather than functions with a name:

| Agent | Role | State |
|---|---|---|
| **Steve** | Strategic reasoning — vision, decision, direction | Flagship demo: voice on Claude Code |
| **Sabino** | Operational execution — summaries, hooks, process | In development |
| **Dolores** | Creative-emotional — narrative, tone | Out of scope (future) |

Underneath it, a **provenance-first knowledge wiki**: raw sources in, contradiction detection, query and synthesis, relationship graph out. Python stdlib only, Markdown on disk, no database until search actually hurts.

**Identity is not role.** Steve is *who* and *how it speaks*; ChiefArchitect is *what it does*. Keeping those separate is what stops an agent from collapsing into a script. → **[Vision & architecture](https://github.com/geovannisoeiro/think-ning-lab)**

### How I work

- **Prototype ≠ validation.** A system that runs is not an idea that is proven.
- **Simplest version that tests the hypothesis.** Complexity has to earn its place.
- **Evidence before architecture.** No framework until something real demands it.
- **Foundations over tools.** Which fundamental survives when this technology disappears?
